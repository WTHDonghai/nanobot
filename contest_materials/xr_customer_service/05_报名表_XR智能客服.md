## 项目简介

西软AI智能客服系统是一套**多通道、可观测、持续学习**的企业级智能客服解决方案，面向酒店、景区、文旅等服务场景。

系统基于OpenViking知识库底座，采用创新的**L0/L1/L2三级层级文件系统**管理产品知识，支持飞书、钉钉、Web、API等多通道统一接入。核心能力包括：精准文档问答、多轮对话理解、知识来源溯源、人工无缝接管、会话记忆持续学习。

---

## 解决的业务问题

1. **客服知识分散**：产品手册、FAQ、历史工单分散在多个系统，客服需频繁切换查找，回答效率和一致性差
2. **重复咨询量大**：70%以上为客户产品使用相关的重复性问题，消耗大量人力
3. **非工作时间无覆盖**：夜间和节假日无人值守，客户咨询无响应
4. **知识传承困难**：资深客服经验依赖个人，培训周期长（2-4周）
5. **服务质量难审计**：客服回答缺乏溯源，错误难发现、质量难提升

## 技术方案概要

- **知识库底座**: OpenViking（自研开源）— L0/L1/L2层级文件系统 + 向量混合索引
- **Agent引擎**: VikingBot — 多通道Agent Loop + 意图路由 + 工具注册
- **通道支持**: 飞书、钉钉、Web页面、REST API
- **核心技术**: 层级递归检索算法、混合索引（Dense+Sparse）、动态活体卡片（钉钉）、会话记忆自动提取
- **部署**: Docker Compose，支持私有化部署
